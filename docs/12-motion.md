# Анимации KUMINOVVV

Анимации дополняют утверждённую композицию главной страницы. Onest, цвета,
изображения, размеры постеров и статический экспорт сохранены.

## Карта поведения

| Область | Поведение |
| --- | --- |
| Навигация и Hero | Навигация, две строки заголовка с маской и задержкой 130 мс, затем описание |
| Проекты | Заголовок и постеры появляются вместе с Hero: видимые карточки мягко сходятся снизу с разных сторон; направления зависят от ширины экрана |
| Галерея | Инерция, мягкая привязка в пределах 64 px, drag/swipe и клавиатурные стрелки без отдельной панели управления |
| Модальные окна | Белый экран на весь viewport, блок контента по своей высоте расположен по центру; fade/scale 300 мс, обратный переход 220 мс; в свободных полях курсор заменяется крестиком для закрытия |
| Мой подход | Заголовок, раскрытие панели и последовательное появление трёх смысловых блоков |
| Creative Lab | Независимые слои оригинального SVG реагируют на курсор, плавно возвращаются в покой |
| Обо мне | Заголовок, биография и одноразовый акцент карточки опыта |
| Контакты | Последовательное раскрытие строк, CTA и ссылок; hover/pressed/focus и движение стрелок |

## Реализация

Новых библиотек нет. Для появления используются Web Animations API и
Intersection Observer; для hover — Tailwind/CSS transitions. У Creative Lab
один requestAnimationFrame на время движения и возврата. В покое цикла нет.

- `src/shared/lib/motion/tokens.ts` — durations, delays, easings, stagger,
  response/precision сглаживания и настройки инерции/привязки.
- `src/shared/lib/motion/reveal.ts` — варианты появления и общие параметры.
- `src/app/globals.css` — вступление Hero и проектов при первом отображении, до гидратации;
  `src/widgets/visual-portfolio/ui/portfolio-motion.tsx` — одноразовые reveal по `data-motion`.
- `model/use-gallery-drag.ts`, `model/use-gallery-position.ts` —
  drag, остановка и мягкая привязка без счётчика и отдельных кнопок.
- `model/use-project-location.ts`, `ui/project-gallery.tsx`,
  `ui/project-modal.tsx`, `model/trap-dialog-focus.ts` — URL, presence,
  enter/exit, блокировка прокрутки и клавиатурный фокус.
- `model/use-orbit-interaction.ts`, `ui/creative-lab-interaction.tsx` —
  ограниченное смещение существующих слоёв same-origin SVG через CSS translate.
- `ui/visual-hero.tsx`, `ui/approach.tsx`, `ui/about.tsx`, `ui/contact.tsx`,
  `ui/creative-lab.tsx`, `ui/project-card.tsx`, `ui/eservice-artwork.tsx` —
  точки применения эффектов; `widgets/home-page/ui/home-page.tsx` — подключение.

Пути `model/` и `ui/` выше находятся в `src/widgets/visual-portfolio/`.

## Доступность и восстановление состояния

Серверный HTML содержит видимый контент, включая пять карточек. Анимация
никогда не является условием его отображения. Повторное посещение секции не
запускает её заново. Переходы по якорю и фокус клавиатурой завершают анимацию
назначения, чтобы не мешать чтению и взаимодействию.

Анимации включены по умолчанию, в том числе когда система задаёт
`prefers-reduced-motion: reduce`. Внизу страницы есть переключатель «Анимации»:
он выключает или включает эффекты сайта, включая reveal, инерцию, mouse follow,
CSS hover, backdrop и прокрутку. Выбор сохраняется в localStorage без изменения
настроек Windows. Если сохранён прежний режим «по системе» или выбора ещё нет,
анимации включены.
Если сохранение недоступно, выбор работает в пределах текущего посещения.

Галерея сохраняет нативную вертикальную прокрутку страницы, trackpad и touch.
Модалки используют полноэкранный белый native dialog и центральную область контента.
Центральный блок имеет собственную высоту и выравнивается по центру.
На узких и низких экранах модалка прокручивается, чтобы весь контент оставался доступен.
При наведении мыши за блок обычный указатель скрывается, на его месте
появляется крестик; щелчок по свободному полю сверху, сбоку или снизу закрывает диалог.
Крестик располагается в отдельном обрезаемом слое: даже у края экрана он
не расширяет прокручиваемую область. При потере фокуса окна крестик скрывается
и обычный курсор восстанавливается.
На клавиатуре и мобильных доступна постоянная кнопка
закрытия; сохранены Tab/Shift+Tab, Escape, восстановление фокуса и Back/Forward.
При переключении RU/EN на главной модалка не размонтируется: перевод меняется
в том же окне, без повторного проигрывания входной анимации.
Открытие карточки создаёт помеченную запись истории; закрытие возвращает
к предыдущей. Закрытие прямой ссылки заменяет текущую запись, сохраняя
остальные query-параметры и hash.

## Проверка

```sh
pnpm exec tsc --noEmit
pnpm run lint
pnpm run build
pnpm run test:gallery
pnpm run test:motion
pnpm run test:motion-preference
pnpm run test:integrity
```

Для браузерных скриптов нужны Python Playwright и Chrome либо Playwright
Chromium. Они сами поднимают временный локальный сервер из `out/` и закрывают
его после проверки. `check-motion.py` сохраняет снимки desktop/mobile в
системный временный каталог.

Браузерные проверки охватывают последовательность Hero, одноразовые reveal,
пять модалок, backdrop, focus trap/restore, URL/history, drag/click, инерцию,
клавиатурные стрелки, reduced motion, no-JS, мобильный swipe, отклик
SVG и отсутствие горизонтального переполнения в обеих темах.

## Ограничения

Четыре постера уже экспортированы едиными PNG. Их hover мягко масштабирует
существующую композицию целиком; независимое движение фонового текста и
центрального объекта потребовало бы отдельных исходных слоёв. У eService
текст и графика остаются отдельными элементами.

В Figma нет заданных motion-треков: тайминги подобраны по задаче и принципам
референса Shopify Design. Shared-element переход не добавлен. SVG и цвета
не переработаны. Автоматизация проверяет Chromium; визуальная оценка
Safari/Firefox на реальных устройствах остаётся отдельной проверкой.
