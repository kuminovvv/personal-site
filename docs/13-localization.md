# Русский и английский языки

Переводы подключены через `i18next`. Русские страницы сохраняют прежние URL,
английские находятся под `/en/`: например, `/projects/soobota/` и
`/en/projects/soobota/`. Язык страницы задаётся URL, обе версии экспортируются
в статический HTML.

## Переводы

- `src/shared/lib/i18n/dictionary.ts` — фабрика словарей i18next.
  Каждому словарю принадлежат отдельные экземпляры для RU и EN. Используется
  `getFixedT`, поэтому рендеры разных языков не меняют глобальное состояние.
- `src/shared/config/site-content.json` и `site-content.en.json` — контент
  каталога, резюме, контактов и общего подвала; структура данных одинакова.
- `project-cases.ts` и `project-cases.en.ts` — полные описания семи кейсов.
- Копии интерфейсных текстов виджетов хранятся в их `model/` и подключаются
  через ту же фабрику i18next.
- `src/shared/lib/i18n/locale.ts` — тип языка и построение локальных ссылок.
  Внешние ссылки и пути изображений не меняются.

Серверные компоненты получают `locale` через параметры компонентов; клиентские
получают тот же сериализуемый параметр. Дополнительный backend для переводов
и определение языка через cookies не требуются.

## Маршруты и переключение

Группы `app/(ru)/` и `app/(en)/en/` используют общий `root-document.tsx` с
правильным `<html lang>`. Страницы задают локализованные metadata, canonical и
hreflang; `sitemap.ts` перечисляет обе версии.

`LanguageSwitcher` доступен в навигации, подвале и модальном окне проекта.
Обычные ссылки сохраняют путь, query и hash, включая открытый `?project=...`.
Переключение языка загружает другой статический документ. Навигация внутри
выбранной версии сохраняет язык. Без JavaScript переводы уже находятся в HTML.

На **первом посещении русскоязычного URL** без сохранённого выбора сайт запрашивает
страну публичного IP через HTTPS API `ipwho.is` (ключ не нужен):
`RU` → русский, остальные страны → `/en/`. Страна определяется только при
отсутствии ручного выбора; автоматический результат кэшируется в `sessionStorage`
в пределах вкладки. Если API недоступен или не отвечает за 2,5 секунды,
используется язык браузера: русский → RU, остальные → EN.
Пока идёт первый запрос, содержимое страницы скрыто, чтобы не показать
неверный язык до переадресации. В дальнейшем кэш или выбор позволяют
сделать переход до первого отображения страницы.

Явное переключение RU/EN сохраняется в `localStorage` под ключом
`portfolio-locale` и имеет приоритет над страной IP и языком браузера,
включая последующие посещения. Переход напрямую на `/en/...` всегда
открывает английский вариант по URL. Автоматическая переадресация сохраняет
путь, query и hash: `/projects/soobota/` → `/en/projects/soobota/`.
Запрос `ipwho.is` раскрывает IP посетителя этому сервису;
геолокация по IP может отличаться от физической страны при использовании VPN.

Изображения существующих проектов сохраняются как оригинальные иллюстрации;
текст самого продукта внутри растрового изображения не является интерфейсом
сайта. Описания и alt-тексты локализованы.

## Проверки

```sh
pnpm exec tsc --noEmit
pnpm run lint
pnpm run build
pnpm run test:i18n
pnpm run test:integrity
```

`test:i18n` проверяет 24 документа, отсутствие непереведённого английского
интерфейса, язык документа, metadata, внутренние ссылки, смену языка с открытым
проектом, клавиатуру, прямую загрузку без JS и адаптивность EN в двух темах.
